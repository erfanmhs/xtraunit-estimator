## 3. The takeoff gesture work (most recent, most fragile)

Three separate root causes were found for "the shape gets confused and starts
choosing random points". All three are in the two commits above.

1. **The multi-touch gate was a stopwatch.** A 250 ms cooldown, armed from the
   census, released on a timer. Too short (committing a pinch means setScale +
   re-render + PDF re-raster) and never armed at all when the census missed a
   finger. Replaced with a latch released only when the glass is clear.

2. **The zoom commits asynchronously.** Pinch previews with a CSS transform and
   commits via `setScale`. Until React re-renders, `getBoundingClientRect()`
   reports the NEW geometry while `scale` is still the OLD number, and
   `clientToPoint` divides one by the other. Gated with `zoomSettling`, cleared
   by an effect on `[scale]`.

3. **Auto-pan fired for a finger holding still** — this was the big one, and it
   has nothing to do with pinching. Any finger inside the 48 px edge margin
   scrolled the sheet, moving or not. Measured: a stationary touch 30 px from
   the right edge scrolled **82 px in under 300 ms**. A phone is 375 px wide,
   so both edges are inside the margin and are exactly where points get placed.
   Now requires the finger to leave the tap slop first.

**`src/lib/takeoff/touchGate.ts`** holds the rule with 13 tests. It was
extracted because this regressed twice while spread across four refs in a
6,000-line component. One test deliberately asserts the *broken* behaviour if a
caller forgets to discount the lifting finger — the capture/bubble ordering trap
that made the latch stick forever.

**Verified live** in the browser pane at 375 px against the real viewer:
pinch mid-Area adds 0 points, existing corners scale by an identical 2.824× on
the same y, the next point lands 0.03 px from the finger, holding at the edge
drifts 0 px, and a deliberate slide still pans 112 px.

**Still owed:** Erfan's actual thumb. `AIM_LIFT = 34` in `PlanViewer.tsx` is a
reasoned starting value (half a fingertip plus clearance), not a measured one.
If points land above where he means, lower it.
