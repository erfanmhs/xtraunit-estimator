# Feedback round — 2026-09-08

Erfan's feedback after extended real use, mostly on **iPhone**. Every item is
numbered so nothing gets lost and each can be ticked off independently.

**Standing rule for this round:** the phone is the design target. The desktop
must stay correct and functional, and gets checked on every item — but where
the two conflict, the phone wins.

Status key: `[ ]` not started · `[~]` in progress · `[x]` done · `[>]` deferred
with a reason.

## Note on verifying G3 on a device

`AIM_LIFT` in `PlanViewer.tsx` is **34 px**, chosen as roughly half a fingertip
contact patch plus clearance. It is a starting value, not a measured one — the
browser pane has no fingers, so this cannot be validated anywhere except on
Erfan's actual phone with his actual thumb.

If points land **above** where he means, lower it. If his finger still covers
the target, raise it. It's one constant with a comment on it.
